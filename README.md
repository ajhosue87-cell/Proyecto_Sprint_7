# Proyecto_Sprint_7
Prototipo de página web

Esta página web es un visualizador de datos acerca de
la dispersión para el conjunto de datos de venta de coches

1. Para ejecutar el programa es necesario tener instalado un editor de texto (VS Code) y un intérprete de Python, posterior a ello, se nececitan instalar
   las librerias correspondientes (streamlit, pandas y plotly) desde la terminal del editor o desde el cdm de tu sistema operativo.
   Por ejemplo, una vez que se sitúe en la misma carpeta donde guardó su programa, el comando para instalar la libreria "streamlit" en Windows es:
   """
   pip install streamlit
   """
   Deberá realizar el mismo procedimiento con las librerias restantes 
2. Una vez que tenga las librerias instaladas, y la terminal abierta,(cmd) podrá ejecutar el porgrama como servidor local desde su computadora/laptop colocándose
   en la ruta donde tenga almacenado el programa y ejecutando el comando:
   """
   streamlit run <NOMBRE DE SU APLICACIÓN>.py
   """
3. El archivo app.py contiene comentarios sobre el funcionamiento interno del código
